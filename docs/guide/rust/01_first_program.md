# A first Rust program

This tutorial and the ones after it are the example programs of the crate
(`metatron-qso-rs/examples`), cut into pieces and explained. The code on
these pages is taken from those files when the documentation is built, and
the output shown is what the programs printed in that build, so neither
can go stale.

Add the crate to a project:

```bash
cargo add metatron-qso-rs
```

The crate is imported as `metatron_qso`. Its prelude brings the common
types into scope: circuits and state vectors, Pauli sums, graphs, the
variational algorithms, optimisers and walks. Every fallible function
returns `metatron_qso::Result`, so `main` can return it and use `?`.

The quick-start program is the one in the README. Each part prints one
line.

## VQE for H₂

`models::h2_sto3g()` is the two-qubit Hamiltonian of H₂ in the STO-3G
basis at 0.735 Å. A one-layer `real_amplitudes` ansatz is enough to reach
its ground state; `with_restarts(4)` starts the optimiser from four random
points and keeps the best. The energy printed includes the nuclear
repulsion.

{{example quickstart.rs:vqe}}

## QAOA for MaxCut

`MaxCutQaoa` builds the QAOA cost and mixer layers of a graph; `p = 2`
layers on Metatron's Cube (the complete graph on 13 nodes). The
approximation ratio is the expected cut over the maximum cut.

{{example quickstart.rs:qaoa}}

## Exact gradients

A circuit can hold symbolic parameters (`new_parameter`). The adjoint
method returns the expectation value and its gradient with respect to
every parameter, at the cost of a few simulations however many parameters
there are.

{{example quickstart.rs:gradient}}

## A quantum walk

A continuous-time walk on the Fruit of Life graph, generated by the
Laplacian, started at node 0 (the centre); `probabilities` returns the
probability of every node at time 2.

{{example quickstart.rs:walk}}
